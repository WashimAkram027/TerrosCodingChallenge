     Team summary for managers

     Context

     The README says managers open the app before their weekly check-in to see
     who is falling behind. Today they have to scan the task lists to work that
     out. This adds a team summary for managers with four things: open tasks,
     overdue tasks, tasks due in the next 24 hours, and reps with overdue tasks.

     Constraints:
     - No new dependencies.
     - Existing API responses and your security fixes stay as they are.
     - The rep experience does not change.
     - The numbers stay accurate after tasks are completed.
     - Loading, empty and error states are handled.
     - New behaviour comes with meaningful tests.

     Timebox: it is 14:26 now. Building stops at about 14:48, then
     SUBMISSION.md.

     Approach

     1. The API does the counting, through a new read-only endpoint, GET 
        /api/tasks/summary.
        - docs/domain.md says the API works out time-based status (isOverdue)
          and the web app only shows it. "Due soon" is the same kind of rule.
        - One server clock keeps "overdue" and "due soon" consistent: a task can
          never be counted as both.
        - The numbers match what the lists show.
        - Existing endpoints and response shapes are untouched.
     2. It reuses the existing scoped query, this.queries.run("all", context, { 
        status: "open" }) from src/api/domain/taskQueries/engine.ts.
        - The summary inherits the visibility rules in scope.ts, so there is no
          third copy of them.
        - A rep calling the endpoint gets counts for their own tasks only, like
          the other task endpoints.
     3. In the web app it is a third tab, "Team summary", shown only to 
        managers.
        - The Tasks and Overdue views stay the same, and so do TaskList and
          useAsync.
        - The tab loads fresh data each time it is opened, so it reflects tasks
          completed in the other tabs without new refresh code.
        - Completing a task doesn't make the page jump.
        - Tasks stays the tab managers land on.
